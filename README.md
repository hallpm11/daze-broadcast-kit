# Daze of Thunder | OBS + Live iRacing Telemetry

**Version 1.3 — source for GitHub Actions to build the Windows team installer ZIP.**

Start with [START_HERE.md](START_HERE.md). The public Windows download is generated by `.github/workflows/build-windows.yml` and includes `DazeTelemetry.exe`. This source archive has *not* been compiled or validated on a Windows/iRacing computer yet.

The telemetry reader is local-only, read-only, zero-configuration, and self-hosted on each broadcaster's own PC. Compatible with both Driver POV and Broadcast Team OBS scenes. No Daze Broadcast AI, manual event entry, or server hosting is required.

Developer tests: `python -m unittest discover -s tests -v`. Preview demo locally: `python launch.py --demo`.

GitHub publishing steps: [GITHUB_UPLOAD.md](GITHUB_UPLOAD.md).
